Ranger’s Path: National Park Simulator

An Unreal Engine 5.6 project, with CommonUI used for the UI. The game is shipped for Steam, MicrosoftStore, SteamDeck, PlayStation 5 and Xbox Series S/X.

As a UI Tech Lead, I oversaw the development lifecycle from the early stages of the game to the final full release of the game. The UI team consisted of 3 members (including myself), though it was later downscaled to only me as the project's manpower requirements decreased.

All implementations are done in C++ with minimal Blueprint usage for a better version control tracking via Perforce. The materials used, as well as the animations implemented, are my own. Some of, in my opinion, most significant outliers of the project:

  • Improving the internal map plugin to add features, such as off-screen indicators, icon overlapping handling, bounds limits and more.
  • Console debugging. Includes a varied assortment of topics, such as researching and creating a guide on how to plug the debugger to PS, custom widget bound collisions calculations required for consoles, certifications or UI scaling to ensure good readability.
  • Collaborations with other departments such as Art, UX/UI, Gameplay and Audio to ensure transparency, definition of requirements and a smooth transition of shared tasks.

Police Simulator

An Unreal Engine 5.6 project, with CommonUI used for the UI. The game is shipped for Steam, MicrosoftStore, SteamDeck, PlayStation 5 and Xbox Series S/X.

As a UI developer my main task in this project was to develop widgets following the UX/UI team specifications. This includes any animations or materials that were required. Code cleanness and scalability was paramount and strongly enforced, something I carried with me later as a UI Tech Lead.

Some outliers are:

  • Rapid personal growth, going from novice to a reliable member of the team in a very short span of time.
  • Developing an internal map plugin with basic features such as panning and manual icon placement controls.
  • Rapid prototyping with the UX team.
