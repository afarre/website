Project 9 - Nagy

Work in progress. Reusing the Sequencer map I created this project to focus in C++ much like my previous tile project, but this time focused on a more "gamified" set of features. Whilst the previous project was great at showcasing C++ excellence in an Unreal environment, it had little in terms of gameplay and the AI, interactions, damage handling and other features that come with it. This project aims to fix that and also adds Data Tables, Data Assets and pure C++ UI to my knowledge pool.


At its present state, the player is capable of picking a primary and a secondary weapon and can cast 2 spells. Enemies have a basic follow AI and a damage system. Melee weapon damage collision has been done with traces. A strong emphasis has been placed in code reusability and abstraction.
Code available on its public GitHub repository.

Project 8 - Tile Selector

This Dynamic Tile selector project allowed me to gain sound programming knowledge with Unreal. This C++ focused project is capable of detecting when the user adds images to a predefined folder, and then it converts the images to textures that can be used in game live. The textures are then used to change the material of the bathroom walls. This project also allows you to take screenshots, save and load and navigate to/edit the folders used to drop images and to store the screenshots taken by the user, all inside of Unreal.
Additional GIFs and code available on its public GitHub repository.

Project 7 - Castle Environment

This project contains a compilation of all the knowledge I had acquired up to this point. Besides the aforementioned topics learned, I also introduced world and local aligned textures and pixel dithering to aid me blend the different meshes that compose the environment. I also introduced some localised VFX particles.
I also expanded on my programming as not only can you interact with elements, but there are damageable enemies and objects that damage the player. While the enemies lack AI, I did implement some AI for the deer scattered around the world. I also added UI elements such as health bars and a menu. I dropped this project some time later as I had learned much with it, but my code was far from clean, and I deemed it more worth to begin a new project with the good practices and knowledge I had acquired while working on this one.

Project 5 - Sequencer

As a second assignment of the Masters, we were to create a Sequence trailer of any topic of our preference. I organically came upon this arena design in which a champion faces against some sort of boss. Whilst the assets, soundtracks and other raw elements are borrowed from free sources such as Sketchfab, the entire composition, camera layout, lighting and so on are entirely of my own doing.
